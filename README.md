# 🧠 BrainCT AI: Dual 50/50 Soft Ensemble Diagnostic Workstation

An explainable multi-label triage workstation for non-contrast brain CT scans powered by a **50/50 Soft Probability Ensemble of DenseNet-121 and VGG-16-BN** with inter-slice attention, calibrated optimal decision thresholds, Grad-CAM++ saliency overlays, and cryptographic blockchain audit trail generation.

## 🌟 Diagnostic Capabilities
- **Multi-Label Detection:** Normal Study, Infarct / Ischemia, Cerebral Atrophy.
- **Flexible Slicing:** Supports single-slice inspection or complete 14-slice volumetric series.
- **Explainable AI:** Dual Grad-CAM++ feature extraction with 50/50 fused saliency overlays.
- **Clinical Reporting:** 1-click structured radiological report generation with SHA-256 digital fingerprint.

## 🚀 Quickstart
```bash
pip install -r requirements.txt
streamlit run app.py
```
